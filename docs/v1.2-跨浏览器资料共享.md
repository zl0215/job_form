# v1.2 跨浏览器资料共享（Chrome ↔ Edge）

日期：2026-11-10。用户反馈：「我在 chrome 浏览器保存的个人信息在 edge 没办法用，现在需要你修改一下，只要是用这个插件信息是共享的」。

扩展资料默认保存在各自浏览器的 `chrome.storage.local`，Chrome 与 Edge 之间没有共享存储。v1.2 在**不引入服务器**的前提下提供两种共享方式，并保持“本地优先、冲突不自动覆盖”的原则。

## 1. 快速共享（剪贴板，一次一传）

设置页 →「数据与同步」→「快速共享」：

- **复制整套资料**：把当前资料生成为与「导出完整数据」相同格式的 JSON 写入剪贴板（不下载文件）。
- **粘贴导入**：另一个浏览器设置页的文本框里 Ctrl+V →「解析并检查」（只显示简历/教育/项目等条数摘要，不显示个人值）→「覆盖并导入」二次确认后导入。

适合临时迁移一次；不申请剪贴板读取权限（由用户手动粘贴）。

## 2. 共享文件自动同步（推荐，长期）

设置页 →「数据与同步」→「共享文件」：

1. 选一个 Chrome 与 Edge 都能访问的文件（如 OneDrive/坚果云同步目录中的 `campus-form-agent-share.json`）；
2. 每个浏览器各绑定一次：一方「新建共享文件」，另一方「选择已有共享文件」；
3. 之后：
   - 在设置页保存资料 → 防抖后自动写入共享文件；
   - 打开设置页「数据与同步」/点「立即同步」→ 自动检查文件与本地差异；
   - 两端都改过 → 显示冲突面板（只显示条数与修改时间），由用户选择「用文件覆盖本地」或「用本地覆盖文件」；
   - 内容相同 → 无操作。

### 文件格式

与现有备份格式兼容（`BackupDocument` v2），附加：

```json
{
  "schemaVersion": 2,
  "exportedAt": "…",
  "source": { "extensionVersion": "1.2.0" },
  "savedAt": "…",
  "sourceExtensionVersion": "1.2.0",
  "data": { "resumeProfileLibrary": {}, "llmConfig": null, "settings": null, "applicationRecords": [] }
}
```

- 解析复用 `backup.ts` 的校验（兼容 v1 备份文档）；
- 共享文件**不携带 WebDAV 凭据**；剪贴板与既有「导出完整数据」一致，含 WebDAV 配置（便于恢复同步设置）；
- 应用文件内容前走既有 `IMPORT_BACKUP` 校验；写入文件后回读并用业务 SHA-256 复核。

### 同步决策

| 本地 | 文件 | 动作 |
|---|---|---|
| 无变化 | 无变化 / 内容相同 | noop |
| 本地有变化 | 文件未变 | upload（写文件并复核） |
| 本地未变 | 文件有变化 | download（校验后导入本地并复核） |
| 双方都有变化 | — | conflict（显示选择，不自动覆盖） |
| 文件被删/清空且曾同步 | — | conflict（提示，避免静默丢失） |
| 首次绑定且内容不同 | — | conflict（默认让用户选择） |

## 4. 安全与隐私

- 共享文件与剪贴板内容为**明文完整资料**（可能含简历 PDF base64、身份证号等），UI 有明确警告；请只放在可信目录/剪贴板。
- 应用远端内容前必须通过既有导入校验；失败不改本地、不更新同步基线。
- 权限失效（浏览器重启、闲置、文件被移动）时只提示「重新授权」，绝不读写。
- 不引入服务器：文件由用户自行选择（可放在自己的网盘同步目录），扩展不主动上传任何地方。

## 5. 边界与未验证项

- 自动同步触发点：设置页「数据与同步」打开时 + 打开期间监听本地资料变化（防抖 800ms）；设置页关闭后不会后台轮询。
- 浏览器重启或闲置后 File System Access 权限可能失效，需要用户点一次「重新授权」。
- 非 Chromium 浏览器（Firefox/Safari）不支持 File System Access，只提供剪贴板方式。
- 两个浏览器同时写同一文件时，受网盘同步延迟影响，冲突检测是尽力而为（不会自动覆盖，但可能看到旧版本）。
- 本轮**未在真实 Chrome+Edge 上验证** FSA 文件选择器、句柄跨重启恢复、双端 upload/download/conflict 全流程与剪贴板往返；单元测试覆盖纯逻辑，构建/冒烟只覆盖扩展加载与扩展页渲染。需要用户按上面步骤实测。
